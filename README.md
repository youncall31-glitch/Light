# 마지막 등대 (The Last Lighthouse)

안개에 삼켜진 마을 사람들을 등대의 빛으로 되찾는 모바일 세로형 로그라이크 디펜스 게임입니다.
설치 없이 `index.html` 하나로 브라우저에서 실행됩니다.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages(Settings → Pages → Branch: `main` / root)로 배포하면 바로 플레이할 수 있습니다.
- 진행 기록(빛의 결정, 단서, 지켜낸 장, 기억 조각)은 브라우저 localStorage에 저장됩니다.

## 구성
- **다섯 개의 장**: 해안 마을 → 갈대 늪 → 폐광 → 난파선 무덤 → 안개의 심장. 장마다 다른 길과 분위기, 10파도(5파도 정예, 10파도 보스).
- **이야기 50조각**: 파도마다 한 줄씩 열리는 기억 조각과 장 시작·끝 이야기.
- **단서와 추리**: 금빛 '기억을 품은 그림자'를 정화해 장마다 단서 4개를 모으고, 사건 5개의 진실을 추리.
- **기억의 퍼즐**: 단서 하나가 퍼즐 한 조각. 20조각과 사건 5개를 모두 풀면 마지막 그림과 엔딩 영상이 완성됩니다.
- **마지막 장 잠금**: 「안개의 심장」은 사건 1~4를 모두 풀어야 열립니다.
- **기억 영상**: 사건마다 절차적 애니메이션 삽화 + 엔딩 영상.

## 마을 사람(타워)
- 작살 · 화염 · 밀물 · 번개 4종.
- 등유로 4단계까지 강화, 같은 종류 4단계 이상 둘을 **합치면** 최고 8단계까지. 단계마다 모습과 별(★·✦)이 바뀝니다.

## 조작
- 받침돌 탭: 세우기 / 강화 / 합치기 / 판매
- 빈 곳을 누른 채 끌기: 등대 빛줄기 조종 (피해 2배)
- 섬광: 주변 그림자 기절 + 큰 피해

## 기술
- 순수 HTML / CSS / JavaScript (Canvas 2D), 외부 라이브러리 없음.
- 폰트: Google Fonts (Gowun Batang, IBM Plex Sans KR).
