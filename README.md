# 마지막 등대 (The Last Lighthouse)

안개에 삼켜진 마을을 등대의 빛으로 지키며, 안개를 부른 범인을 추리하는 모바일 세로형 로그라이크 디펜스 게임입니다.
설치 없이 `index.html` 하나로 브라우저에서 실행됩니다.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages(Settings → Pages → Branch: `main` / root)로 배포하면 바로 플레이할 수 있습니다.
- 진행 기록은 브라우저 localStorage에 저장됩니다.

## 이야기
바닷가 마을 깊은 사당에는 바다에 잠긴 이의 목소리를 들려주는 안개가 검은 등불에 봉인되어 있었다. 등대의 빛이 매일 밤 사당을 비추는 한 봉인은 풀리지 않는다. 안개는 빛 아래에선 퍼지지 못하고 어둠 속에서 번진다.
사흘 전, 빛이 닿지 않는 썰물의 갯바닥에서 누군가 봉인을 열었다. 안개를 마신 사람들은 죽은 가족의 목소리를 듣지만 만질 수도 볼 수도 없어 갈증만 커지고, "빛만 사라지면 모두 채워 주겠다"는 안개의 거짓 약속에 이끌려 그림자가 되어 마지막 빛, 등대를 끄러 온다.
스승이 떠난 뒤 열 해 동안 혼자 등대를 지켜 온 당신은 그림자를 빛으로 정화하며 봉인을 연 사람을 추적한다. 범인은 함께 싸우는 사람 중 하나다.

이야기는 약 120조각으로 나뉘어 있다: 파도마다 열리는 기억 조각 50, 정예·보스가 남기는 스승의 일지 10, 타워를 키우며 열리는 인물 기억 20, 증거 20, 회의 변론과 장 시작·끝.

## 상징
- 바다는 죽음, 뭍은 삶, 썰물의 갯바닥은 그 경계. 안개는 경계를 흐리는 중독, 검은 등불은 거짓 위로의 근원, 등대 빛은 애도와 기억.
- 봉인(덮어 두기)으로는 끝나지 않는다. 등대의 불씨를 검은 등불에 옮겨 붙여야(애도) 검은 불꽃이 따뜻한 불로 바뀐다.

## 구성
- **목판화 그림 이야기**: 프롤로그, 장마다 시작·끝, 에필로그를 거친 목판화 일러스트와 올라가는 글자로 보여 준다.
- **물때**: 파도마다 썰물과 밀물이 바뀐다. 썰물엔 경계가 열려 그림자가 강해지고, 밀물엔 바닷가 받침돌이 잠겨 그 위 타워가 쉬며 물귀신이 바다에서 해안 길로 올라온다.
- **바다의 목소리**: 가끔 마을 사람이 목소리에 붙잡혀 멈춘다. 보라색 안개 줄기와 말풍선으로 보이고, 거울 빛을 비추면 깨어난다.
- **위령등**: 정예와 보스가 부르던 잃은 이의 이름 10개를 모은다.
- **불씨 옮기기**: 마지막 보스 뒤, 정화된 하람이 불씨를 들고 길을 거슬러 검은 등불까지 걸어간다. 그를 지켜야 끝난다.
- **다섯 개의 장**: 해안 마을 → 갈대 늪 → 폐광 → 난파선 무덤 → 안개의 심장. 장마다 다른 길, 정예, 보스. 이야기 50조각.
- **증거 추리**: 금빛 그림자를 정화해 장마다 증거 4개를 모은다. 결정적인 증거 2개 + 답 1개를 함께 제출해야 풀린다. 사건은 소거법으로 풀리도록 설계.
- **설계도 퍼즐 → 신형 무기**: 장을 지켜내면 9조각 설계도를 위치·방향에 맞게 맞춰 영구 무기를 얻는다.
  - 렌즈 포대(관통 광선) · 안개 종(기절, 적 강화 해제) · 축복 등롱(주변 강화) · 닻 사슬(끌어당기기) · 새벽 거울(빛 반사)
- **등대 회의**: 2장부터 장을 시작할 때마다 각자의 변론을 듣고, 그 밤 한 사람을 몰래 지켜본다(타워는 그대로 씀). 등대 빛이 흐려지면 빛줄기가 보라색으로 바뀌고 상단에 표시된다. 하람을 지켜본 밤엔 그가 렌즈 곁에서 들킨다.
- **거울 빛**: 거울 버튼을 누르고 원하는 곳을 누르면 등대 빛이 8초 동안 모인다. 빛 안의 그림자는 느려지고 40% 더 다치며 강화가 지워지고, 빛 안의 타워는 빨라지고 강해진다. 재사용 20초.
- **그림자 종류**: 그림자 · 날쌘 것 · 덩치 · 울보(쓰러지면 둘로 갈라짐) · 부르는 자(주변을 재촉) · 물귀신(밀물 때 바다에서) · 정예 · 보스. 모두 길을 따라온다.
- **반전**: 마지막 장에서 범인의 타워가 등을 돌려 적을 강화한다. 안개 종으로 봉인하거나 끌어내려야 한다.
- **강화**: 타워마다 등유로 바로 8단계까지. 4단계 각성, 8단계 전설.

## 조작
- 받침돌 탭: 세우기 / 강화 / 판매
- 거울 버튼 → 빈 곳 탭: 거울 빛 모으기
- 섬광: 주변 그림자 기절 + 큰 피해

## 기술
- 순수 HTML / CSS / JavaScript (Canvas 2D), 외부 라이브러리 없음.
