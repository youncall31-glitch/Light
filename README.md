# 마지막 등대 (The Last Lighthouse)

안개에 삼켜진 마을 사람들을 등대의 빛으로 되찾는 모바일 세로형 로그라이크 디펜스 게임입니다.
설치 없이 `index.html` 하나로 브라우저에서 실행됩니다.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages(Settings → Pages → Branch: `main` / root)로 배포하면 바로 플레이할 수 있습니다.
- 진행 기록(빛의 결정, 단서, 기억 조각)은 브라우저 localStorage에 저장됩니다.

## 주요 기능
- **마을 사람 4종**: 작살 · 화염 · 밀물 · 번개. 4단계 강화마다 모습이 바뀌고 별(★)이 늘어나며, 4단계는 각성.
- **빛줄기 조종**: 빈 곳을 누른 채 끌면 등대 빛을 직접 비춤 (피해 2배).
- **섬광**: 주변 그림자 기절 + 큰 피해.
- **빛이 남긴 선물**: 파도마다 카드 3장 중 1장 선택 (일반/희귀/전설), 시너지.
- **단서와 추리**: 금빛 '기억을 품은 그림자'를 정화해 단서를 모으고, 사건 3개의 진실을 추리.
- **등불**: 등대의 생명이자 빛줄기 세기. 0이 되면 패배.
- **등대 작업실**: 빛의 결정으로 영구 강화.

## 기술
- 순수 HTML / CSS / JavaScript (Canvas 2D), 외부 라이브러리 없음.
- 폰트: Google Fonts (Gowun Batang, IBM Plex Sans KR).
